# Ahmet Kandemir Pehlivanlı | Digital Archive & Portfolio

Welcome aboard! This repository hosts the source code for my personal website, digital portfolio, and library. 

I view engineering as a quest for harmony—a natural flow between the physical, the logical, and the living. This space serves as a central hub connecting my experiences in macro-level critical infrastructure, low-level system programming, and biomedical engineering.

## Architecture & Philosophy

This project is built with a **Zero-Dependency** philosophy. To reflect the deterministic and low-level control principles I value in systems programming, this website avoids heavy frameworks or bundlers. 

## Design Language:

A blend of Hellenistic harmony and retro-terminal / CRT aesthetics.
